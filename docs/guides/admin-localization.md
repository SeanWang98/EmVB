# 后台语言适配

此 fork 从 `0.8.0-dev.2` 提供简体中文界面。
无需修改 EmDash 核心或内容结构。

## 语言来源

EmDash 将当前后台语言同步至 `<html lang>`。
EmVB 通过 `useSyncExternalStore` 订阅此属性。
同一共享 observer 只观察 `lang` 属性。
语言切换重新渲染文案，不重挂画布。
未保存输入与选择状态保留。
服务端渲染使用英文快照。

`zh`、`zh-CN`、`zh-SG` 与 `zh-Hans` 使用简体中文。
`zh-Hans` 的地区后缀与下划线写法同样生效。
英文、繁体中文及未支持语言使用英文。
缺少词条时显示英文源文。

宿主插件描述符的标签接口只接受静态字符串。
侧栏入口和字段选择器因此使用中英双语标签。
插件页面和画布内的文案跟随后台语言。
不使用页面文本扫描或 DOM 文案替换。

## 覆盖范围

界面覆盖工具栏、命令、图层、元素和属性面板。
站点样式、主题条件、页面设置和规则使用中文。
页面列表、初始化、AI 助手与访问提示使用中文。
媒体、图标、图片编辑和画布工具使用中文。
按钮、提示、确认框和无障碍名称使用同一词典。
添加元素和命令搜索保留英文技术名搜索。
已有英文测试保持默认英文环境。

常见客户端错误按错误码或结构翻译。
未知 API 错误及底层校验路径保留原文。
这样可以保留服务端诊断细节。

## 数据边界

只在显示边界调用翻译器。
用户标题、正文、slug 和标签原样显示。
样式类名、变量名和自定义分群名原样显示。
CSS 值、节点类型、图标 ID 和存储枚举不翻译。
搜索可添加中文别名，但保持原有 ID。
菜单分隔和行为判断使用稳定 ID，不比较译文。
组件 key 使用稳定数据，不使用译文。
本地错误保存源消息与参数，在显示时翻译。
API 原文单独保存，不将其作为词条键。
短时通知和语音播报使用触发时的语言。

此功能不创建内容翻译或翻译组。
它不改变 Page 保存、修订和发布流程。
站点样式继续独立保存与发布。

## 扩展词条

词典位于 `packages/emvb/src/admin/i18n/`。
按职责维护中文词典，入口统一合并。
英文源文是键，中文显示是值。
不要将用户值作为消息键。
同词不同义时使用明确的上下文消息。

```tsx
const t = useI18n();
return <button>{t("Cancel")}</button>;
```

动态文案用命名参数传入用户值。
译文保留源文中的全部参数名。
参数以文本插值，不解析 HTML。

```tsx
t("Rename {name}", { name: userLabel });
```

React 组件使用 `useI18n()` 订阅语言。
事件和纯显示辅助函数可以使用 `translate`。
共享纯函数默认英文，必要时接受 `Translate` 参数。
`core` 不导入后台词典、React 或 DOM。

## 验证

运行 `bun run check` 与 `bun run pack:smoke`。
语言测试覆盖词条参数、回退和订阅重连。
界面测试覆盖中文搜索、动态提示与内容保真。
切换语言测试同时检查未提交输入保留。
安装后在宿主后台检查 Page 画布和主题构建器。
仅查看和选择即可验收，语言验收无需发布内容。
